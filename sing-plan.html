zanoza: v2rayA → sing-box migration

State as of 2026-09-01, branch main (all changes staged, not yet committed). Goal: automatic failover between VLESS/REALITY exits when one gets blocked — v2rayA with Xray core can't do it (leastping needs v2ray-core's observatory); sing-box's urltest group can.

Decisions (already made)

  • Scope M — sing-box also absorbs the host-level tv-proxy-router's RU-direct routing (that xray service is deleted); redsocks points straight at the container.
  • Same nixos-container placement, same IP 172.16.64.108, same SOCKS port 20170 → arr apps, beez telegram (socks5h://192.168.89.207:20170) and the TV redsocks chain need zero changes.
  • Failover: selector tag exit (default auto) wrapping a urltest tag auto over all exits; metacubexd dashboard can pin one manually.
  • Secrets: keep the sops URI blob — a Python ExecStartPre parses vless:// URIs at service start into /run/sing-box/10-outbounds.json (sing-box -C merges the dir). Adding/removing an exit = sops edit only.
  • Full rename: custom.containers.sing-box, /tank/sing-box, sing-box.sbulav.ru, Loki job sing-box, dashboard device ve-sing-box. Ports 20171/20172 dropped (no repo consumers). enableTun dropped.

Copy the v2raya: block to sing-box: (keys vless_uris, admin_password). Additive — the old block stays for rollback. Needs a machine whose age key is a recipient of secrets/zanoza/* (mba13, nz, or zanoza itself).

Gotchas / heads-up

  • Port 20172 is gone. Any shell exporting HTTPS_PROXY=http://192.168.89.207:20172 (old v2rayA HTTP port) must switch to 20170 — the sing-box mixed inbound speaks both SOCKS5 and HTTP CONNECT.
  • mba13's static Wi-Fi DNS (94.124.205.83/.204.83) was dead on 2026-09-01; a temporary cache.nixos.org pin was appended to /etc/hosts there (the dotnix activation script overwrites it on the next darwin rebuild).
  • Generator refuses to start with zero parsed URIs (fail-loud, no silent direct-only proxy); it skips non-vless / non-REALITY lines with stderr warnings.
  • Selector pin + urltest history persist in /tank/sing-box/state/cache.db across restarts of the ephemeral container.

Rollback

Single commit: git revert + rebuild restores v2rayA. Its /tank/v2raya data and the v2raya: sops block are untouched until step 5.
